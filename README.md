# Job Portal Management System

## Overview
The **Job Portal Management System** is a web-based application designed to connect job seekers with recruiters. It provides a platform where candidates can search and apply for jobs, while recruiters can post job vacancies and manage applications.

## Features
- User Registration and Login
- Job Seeker Profile Management
- Recruiter Management
- Job Posting and Management
- Search and Browse Job Opportunities
- Apply for Jobs
- Manage Job Applications
- Database Integration

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/rohantingare14/Job-Protal-.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Job-Protal-
   ```

3. Import the project into Eclipse as an Existing Maven Project.

4. Update Maven dependencies:

   ```bash
   mvn clean install
   ```

5. Configure your database connection if required.

6. Run the application from Eclipse.
